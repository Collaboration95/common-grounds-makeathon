What it
cost

300 million tokens. A $2.79 API bill. And it still ran dry before the demo.

On Sunday I built The Commons, a room that builds itself. You wish for a creature, Codex writes it, tests it and draws it, and about a minute later it walks into a shared room with your name on it.

I kept every token, prompt and timestamp from the day. This is the money side of it: what two coding agents burned building it, what the one real bill came to, and what a single wished-for pet costs to make.

01 · The day in tokens

Where the hours
and tokens went

The night before, parallel agents prototyped ten ideas. At 10:01 the organisers put the prize slide up, and by 10:48 every one of those ten was gone. That overnight work cost about $44 in tokens at API prices, and none of it shipped.

The build itself took 2 hours 47 minutes and ate 54% of the day's tokens. Hover over the chart to scrub through the day in 15-minute slices.

02 · Re-reading is the job

96% of it was
the agent re-reading

An agent re-reads its whole conversation on every turn. Prompt caching makes those re-reads cheap, so they dominate the token count but not the bill. Only about 2 million tokens were actually generated all day. Without caching, the same day would have cost about $1,080 instead of $150.

04 · The real bill

$2.79, and it
still ran out

Everything above is an estimate at API list prices. I paid none of it. Claude Code ran on my subscription, and Codex ran through its CLI on my ChatGPT login, which also covered all 93 sprite sheets.

The only pay-as-you-go piece was an OpenAI API key, used to redraw the venue photo into the house style. The whole weekend on that key came to $2.86.

I'd left almost nothing on the key. A few minutes before the demo the balance hit zero, and I had to rush a top-up so the room could still redraw itself on stage.

06 · Making it faster

Three minutes
to 44 seconds

Once the room was public, real people were waiting on their pets. Under load a pet took about 3 minutes. The Codex logs showed why: the drawing step called the image tool three to six times per pet, because saving the picture kept failing.

Two fixes did most of the work. The model now draws exactly once and the server picks the image up itself. And drawing and coding start while the wish is still being screened, instead of after it.

07 · Keeping it alive

The biggest bill
is the server

Public voting runs for three days, so the room has to stay up for three days. On the day it ran on my laptop: close the lid and the link dies, restart it and you get a new URL. So I moved it to AWS.

  • 4 vCPU, 8 GB, paid from AWS credits
  • Tailscale Funnel: permanent HTTPS, free

  • Every pet is still built by Codex

Moving from a Mac to Ubuntu broke three things:

SandboxCodex's sandbox needs unprivileged user namespaces. Ubuntu 24.04 blocks them by default.
sipsThe server shelled out to sips, an image tool that only exists on macOS.
pythonThe model kept calling python on a box with only python3. It drew the sprite sheets, then couldn't save them.
