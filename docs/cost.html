How these are worked out
  • List prices per million tokens: Haiku 5.5 $0.10 in / $0.50 out; Sonnet 5.5 $2 in / $10 out. Cached input is billed at a tenth of the input price; writing the cache costs 1.25×.
  • A screen sends about 1,600 tokens and gets about 130 back.
  • A build sends a ~5,000-token prompt (the creature contract, two samples, the rules). About 90% of it is read from the prompt cache. The reply is about 1,200 tokens of code.
  • Averages come from 29 builds and 43 screens per model, measured from the token counts the API returns, including the occasional repair turn.
  • Pet counts above divide $100 by these averages. They are estimates, not a quote.

Every call is priced and logged, and the test harness refused to go past $8. Sonnet was 7% of the calls and 93% of the bill. A few extra cents went on the box tests.

Not on the $100

  • Drawing the sprite sheet (~45 s per pet). Claude can't generate images, so it still runs on the ChatGPT login through Codex. This is the step that could still hit a ChatGPT limit.
  • The AWS box that hosts the vote: a Lightsail instance at roughly $84 a month list price, tagged to be deleted after 15 Oct.
  • Room-photo redraws use an OpenAI API key, so that is its own small bill.
  • The next step: price the OpenAI image API for the sprite sheets, so the whole pipeline can leave the ChatGPT login. Not measured yet.

Safeguards The live server stops calling Claude once the spend log reaches $80, and the model can be flipped back to Codex with one command, no restart: node tools/set-models.mjs luna

Numbers measured 13 Oct 2026 with the repo's eval harness (eval/): 43 wishes, 29 builds per model. Prices are Anthropic's list prices for prompts under 100K tokens. Full write-up: gist-claude-switch.md.
